## AVD 无法 remount

Android Studio 启动的 AVD 默认无法 `adb remount`。参考 `idea.log` 中的启动命令：

```bash
emulator.exe -netdelay none -netspeed full -no-snapstorage -avd Automotive_Ultrawide -qt-hide-window -grpc-use-token -idle-grpc-timeout 300
```

加上 `-writable-system` 参数手动启动即可：

```bash
emulator.exe -netdelay none -netspeed full -no-snapstorage -avd Automotive_Ultrawide -writable-system
```

注意：

- 如果指定 AVD 路径，需要配置环境变量 `ANDROID_AVD_HOME`
- 建议使用 Android 原生 adb

## Android 16 Automotive 模拟器

A16 没有标准的 AA（Android Automotive）模拟器，需要自己实现：

1. 复制 A14 的 AA AVD ini 文件，修改其中的 avd 配置
2. 用 `-sysdir` 指定自己编译的镜像启动：

```bash
emulator -avd Automotive_Ultrawide_a16 -sysdir D:\sdk-repo-linux-system-images\x86_64
```
