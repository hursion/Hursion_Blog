## 搭配 SSH 使用 gitk 报错

远程执行 `gitk ./` 时报错：

```text
application-specific initialization failed: no display name and no $DISPLAY environment variable

Error in startup script: no display name and no $DISPLAY environment variable
    while executing
"load /usr/lib/x86_64-linux-gnu/libtk8.6.so Tk"
    ("package ifneeded Tk 8.6.5" script)
    invoked from within
"package require Tk"
    (file "/usr/bin/gitk" line 10)
```

原因是没有 X11 显示环境。添加环境变量即可（需 SSH 开启 X11 转发，即 `ssh -X`）：

```bash
export DISPLAY=localhost:10.0
echo $DISPLAY
# localhost:10.0
```

## 终端全屏切换

将以下内容添加到 `keybindings.json`（可通过[键盘快捷键编辑器](https://code.visualstudio.com/docs/getstarted/keybindings)访问）：

```json
[
    {
        "key": "ctrl+alt+m",
        "command": "workbench.action.toggleMaximizedPanel",
        "when": "!terminalFocus"
    },
    {
        "key": "ctrl+`",
        "command": "-workbench.action.terminal.toggleTerminal",
        "when": "!terminalFocus"
    },
    {
        "key": "ctrl+alt+m",
        "command": "workbench.action.terminal.toggleTerminal",
        "when": "terminalFocus"
    }
]
```

## Windows 下用 SSHFS 挂载远程目录

通过 SSH 协议把远程服务器目录挂载成本地盘。参考：[知乎教程](https://zhuanlan.zhihu.com/p/314245985)

需要安装：

- [sshfs-win](https://github.com/billziss-gh/sshfs-win/releases)
- [winfsp](https://github.com/billziss-gh/winfsp/releases)
- [SSHFS-Win Manager](https://github.com/evsar3/sshfs-win-manager/releases)（GUI，可选）
